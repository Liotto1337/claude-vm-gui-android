# Claude VM для Android

Android-версия клиента для Claude Code, который запущен на ВМ (Ubuntu) в tmux. Форк Windows-приложения `claude-vm-gui` 0.2.2 (https://github.com/Liotto1337/claude-vm-gui, remote `upstream`): тот же интерфейс в стиле claude.ai и та же логика на TypeScript, но в WebView Capacitor; SSH и хранение секретов — нативно на Kotlin, связь в фоне и уведомления о сессиях.

Репозиторий: https://github.com/Liotto1337/claude-vm-gui-android. Работа идёт в ветке `android-0.1` по плану `docs/superpowers/plans/2026-10-21-claude-vm-gui-android.md`.

## Как пользоваться (цель версии 0.1.0)

1. В настройках — адрес ВМ, пользователь, импортированный SSH-ключ или пароль.
2. Подключение: TCP:22 → SSH → tmux. Новый сервер — сверка отпечатка ключа.
3. Список сессий — выдвижная панель (☰ или свайп от левого края). Долгое нажатие — меню сессии.
4. Пока работает claude — лента переписки и карточка меню; иначе терминал со строкой клавиш Esc, Tab, Ctrl, стрелки.
5. Свёрнутое приложение держит связь и присылает уведомления «Claude закончил» и «Claude ждёт ответа» — только по сессиям с отметкой «Отслеживать» (меню сессии).
6. Новая версия на GitHub — баннер «Доступно обновление» вверху (версия 0.2).
7. В шапке сессии — процент контекста: нижний лист с разбивкой (как `/context`), «Токенов до автосжатия» и «Сжать сессию» (версия 0.3).
8. Файлы, которые Claude сделал для вас, он кладёт в `~/.cache/claude-vm-gui/outbox` — под ответом карточка: картинка, текст, «Открыть в браузере» для HTML, «Сохранить» в «Загрузки» (версия 0.4). Меню Claude Code собирает выбор касаниями и отправляет его кнопкой «Ответить» / «Готово».
