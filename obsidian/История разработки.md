# История разработки

Часть [[Claude VM для Android]].

## 2026-10-18

- Согласованы подход (терминал в оболочке claude.ai), стек (Electron) и макет из 5 экранов.
- Написана спецификация, заведён репозиторий. Кода пока нет. Подробности — [[Дизайн и решения]].
- Написан план реализации из 13 задач: `docs/superpowers/plans/2026-10-18-claude-vm-gui.md`.
- Task 1: каркас Electron + React, безопасные настройки окна, git-хук против утечки адреса ВМ.
- Task 2: чистые функции и их тесты (58 тестов), фикстура ответа `initialize`.
- Task 3: конфигурация подключения и мост IPC между интерфейсом и главным процессом.
- Task 4: проверка ping (предупреждение) и TCP (обязательна) перед подключением.
- Task 5: SSH-соединение, проверка ключа хоста по known_hosts, автопереподключение; тестовый ключ только для localhost.
- Task 6: сервисы tmux и терминала; команды tmux адресуют сессию по точному имени, чтобы не задеть похожие.
- Task 7: подсказки команд, моделей, файлов и папок; загрузка картинок по SFTP.
- Task 8: экран подключения, настройки, проверка ключа нового сервера; сервисы подключены к интерфейсу.
- Task 9: главное окно — список сессий, шапка, терминал xterm.js, создание и завершение сессий.
- Task 10: поле ввода в стиле claude.ai — подсказки команд и файлов, вставка картинок, выбор модели и effort.
- Task 11: сквозной E2E-сценарий с обрывом связи; после переподключения «Подключено» показывается только когда терминал снова в сессии. Скриншоты в `docs/screenshots/`.
- Task 12: сборка под Windows (NSIS + portable), CI на windows-latest, README со скриншотами, лицензия MIT.
- Task 13: проверка с настоящим claude (подсказки скиллов, /model, /effort, картинка); добавлена защита от отправки в открытое меню Claude Code.
- Финальное ревью: исправлены выполнение текста в bash без claude, таймаут окна ключа сервера, подмена типа ключа, кириллица в подсказках файлов, двойная отправка, точка в имени сессии, медленное обнаружение обрыва, гонка при открытии сессии, запуск хуков проекта при запросе подсказок.
- Копирование и вставка в терминале: Ctrl+C при выделении, Ctrl+Shift+C/V, правая кнопка мыши.
- Версия 0.1.1: релиз со сборкой под Windows через CI (тег v0.1.1).
- Буфер обмена: скопированное в Claude Code и tmux (`tmux load-buffer -w` → OSC 52) попадает в буфер Windows; выделение с Shift больше не сбрасывается, когда Claude Code отслеживает все движения мыши; чтение и запись буфера через главный процесс.
- Версия 0.1.2: буфер обмена через OSC 52 и выделение с Shift (тег v0.1.2).
