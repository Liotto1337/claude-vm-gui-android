# Стек и запуск

Часть [[Claude VM для Android]].

## Стек (версии зафиксированы точно)

- Vite 8.3.4 (корень — `src/renderer`, сборка в `dist/`), React 19.3.1, TypeScript 5.9.3; Electron удалён
- ssh2 1.17.0, @xterm/xterm 6.0.0 + @xterm/addon-fit 0.11.0
- Шрифты: @fontsource/source-serif-4, @fontsource/jetbrains-mono (OFL)
- Тесты: Vitest 5.0.5 (проекты `unit` и `integration`), Playwright 1.64.1 (`_electron`)

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Интерфейс в браузере (Vite) |
| `npm run build` | Сборка в `dist/` |
| `npm test` | Модульные тесты |
| `npm run test:int` | Интеграционные тесты против ВМ |
| `xvfb-run -a npm run test:e2e` | E2E на сервере без экрана |
| `npm run typecheck` | Проверка типов |

## Конфигурация

- `vm.config.json` (в `.gitignore`) — адрес ВМ для разработки; образец — `vm.config.example.json`.
- `CVG_USER_DATA` — отдельная папка настроек (для тестов).
- `CVG_KNOWN_HOSTS` — свой known_hosts (тесты); `CVG_FAKE_CLAUDE=1` — процесс `cat` считается claude (E2E без настоящего claude).
- `CVG_TMUX_SOCKET` (в коде — `knobs.tmuxSocket`) — отдельный сервер tmux (`tmux -L`), `CVG_DEMO_HOST` — показывать этот адрес вместо настоящего, `CVG_TEST_HOOKS=1` — хук обрыва связи для E2E, а на Linux — шифрование пароля без хранилища ключей (`safeStorage.setUsePlainTextEncryption`).
- `CVG_CLAUDE_CMD` — команда вместо `claude` при запуске в сессии (тесты: `node tests/fixtures/fake-claude.mjs`).
- `CVG_CLAUDE_DIR` — каталог Claude Code на ВМ вместо `$HOME/.claude` (тесты); фейковый claude: `CVG_FAKE_SEED` — начальный журнал, `CVG_FAKE_SLOW_ACCEPT=1` — медленное принятие.
- Под root на Linux Electron запускается с `--no-sandbox` (только тесты).
- Снимки экранов для фикстур: `node scripts/dev/fake-anthropic.mjs` (порт 8787) и `scripts/dev/capture-screen.sh start|text|keys|paste|save|stop` — настоящий claude с `ANTHROPIC_BASE_URL` на фейковый API.

## Тестовый SSH-ключ

`~/.ssh/cvg_test_ed25519` на ВМ, в `authorized_keys` с `from="127.0.0.1,::1"` — вход только с самой ВМ. Интеграционные и E2E-тесты без него пропускаются.
