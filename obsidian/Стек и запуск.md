# Стек и запуск

Часть [[Claude VM для Android]].

## Стек (версии зафиксированы точно)

- Vite 8.3.4 (корень — `src/renderer`, сборка в `dist/`), React 19.3.1, TypeScript 5.9.3; Electron удалён
- ssh2 1.17.0 (только dev-мост), ws 8.22.0, tsx 4.23.15, @xterm/xterm 6.0.0 + @xterm/addon-fit 0.11.0

## Android

- Capacitor 8.5.3 (`@capacitor/core`, `android`, `cli`), плагины: keyboard 8.0.6, app 8.1.2, preferences 8.0.1, clipboard 8.0.1, browser 8.0.5, status-bar 8.0.4; иконка и заставка — `@capacitor/assets` 3.0.5 из `assets/logo.png`.
- Gradle 8.14.3, AGP 8.13.0, Kotlin 2.2.0, coroutines 1.10.2; compileSdk/targetSdk 36, minSdk 26; JDK 21.
- `applicationId` `io.github.liotto1337.claudevm`, имя «Claude VM».
- На сервере: JDK 21 (`/usr/lib/jvm/java-21-openjdk-amd64`), SDK в `/opt/android-sdk` (platform-tools, platforms;android-36, build-tools 36 и 35); окружение — `source scripts/android-env.sh`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Интерфейс в браузере (Vite) |
| `npm run build` | Сборка в `dist/` |
| `npm run android:build` | Веб-часть `--mode android` → проверка, что dev-моста нет в бандле (`scripts/check-no-devbridge.mjs`) → `cap sync` → debug APK `android/app/build/outputs/apk/debug/app-debug.apk` |
| `npm run android:run` | То же и запуск на эмуляторе или устройстве |
| `npm run test:android` | JUnit и Robolectric (`gradlew testDebugUnitTest`) |
| `npm run bridge` | Dev-мост: SSH для интерфейса в браузере (`CVG_BRIDGE_PORT`, `CVG_BRIDGE_KEY`, `CVG_BRIDGE_PASSWORD`, `CVG_KNOWN_HOSTS`) |
| `npm test` | Модульные тесты |
| `npm run test:int` | Интеграционные тесты против ВМ |
| `npm run test:e2e` | E2E: сборка `dist/`, `vite preview`, dev-мост на каждый тест |
| `npm run typecheck` | Проверка типов |

## Конфигурация

- `vm.config.json` (в `.gitignore`) — адрес ВМ для разработки; образец — `vm.config.example.json`.
- `CVG_USER_DATA` (E2E) — папка теста: `config.json` для первого запуска и профиль Chromium (localStorage переживает перезапуск).
- `CVG_KNOWN_HOSTS` — свой known_hosts (тесты); `CVG_FAKE_CLAUDE=1` — процесс `cat` считается claude (E2E без настоящего claude).
- `CVG_TMUX_SOCKET` (в коде — `knobs.tmuxSocket`) — отдельный сервер tmux (`tmux -L`), `CVG_DEMO_HOST` — показывать этот адрес вместо настоящего, `CVG_TEST_HOOKS=1` — хук обрыва связи для E2E, а на Linux — шифрование пароля без хранилища ключей (`safeStorage.setUsePlainTextEncryption`).
- `CVG_CLAUDE_CMD` — команда вместо `claude` при запуске в сессии (тесты: `node tests/fixtures/fake-claude.mjs`).
- `CVG_CLAUDE_DIR` — каталог Claude Code на ВМ вместо `$HOME/.claude` (тесты); фейковый claude: `CVG_FAKE_SEED` — начальный журнал, `CVG_FAKE_SLOW_ACCEPT=1` — медленное принятие.
- Снимки экранов для фикстур: `node scripts/dev/fake-anthropic.mjs` (порт 8787) и `scripts/dev/capture-screen.sh start|text|keys|paste|save|stop` — настоящий claude с `ANTHROPIC_BASE_URL` на фейковый API.

## Тестовый SSH-ключ

`~/.ssh/cvg_test_ed25519` на ВМ, в `authorized_keys` с `from="127.0.0.1,::1"` — вход только с самой ВМ. Интеграционные и E2E-тесты без него пропускаются.
