# Структура кода

Часть [[Claude VM для Android]]. Сервисы, работающие с ВМ, живут в `src/core` и получают `SshTransport`; Electron удалён.

| Путь | Назначение |
|---|---|
| `capacitor.config.ts` | Capacitor: `webDir: dist`, клавиатура `resize: native` |
| `android/` | Проект Android (Gradle). `app/src/main/java/io/github/liotto1337/claudevm/`: `MainActivity.kt` (регистрирует плагин), `VmBridgePlugin.kt` (мост JS ↔ `SshHub`: методы `VmBridgePlugin` из `src/platform/android.ts`, ошибки — reject с кодом `NOT_CONNECTED`) |
| `android/.../bridge/SshHub.kt` | Единственное SSH-соединение процесса (переживает пересоздание Activity и перезагрузку WebView): connect с тем же адресом при живом соединении — без переподключения; вопрос про ключ хоста ждёт `answerHostKey`; секреты с проверкой ключа (`KeyImport`) |
| `android/.../bridge/ChunkBatcher.kt` | Пачки каналов → одно событие `chunks` не чаще раза в 16 мс; `closed` уходит после пачек своего канала |
| `android/.../ssh/SshSession.kt` | SSH на sshj: TCP → рукопожатие → вход (`AuthNone` узнаёт методы сервера, дальше `AuthPlan`: ключ → пароль → keyboard-interactive), ключ хоста с вопросом (таймер 20 с замирает на время вопроса, ответ ждётся до 120 с), известный хост — только его типы ключей; exec (stdin, таймаут), каналы-потоки и PTY с `resize`, SFTP с правами 0600, keepalive 30 с × 3, обрыв → `onLost` и переподключение 1–2–5–10–30 с (неинтерактивно), `forceReconnect`, полный BouncyCastle вместо урезанного Android |
| `android/.../ssh/HostKeys.kt`, `AuthPlan.kt`, `Backoff.kt`, `Channels.kt`, `Types.kt` | known_hosts как `known-hosts.ts` (простые, с портом, хешированные), порядок входа, паузы переподключения, нумерация пачек каналов (`ChunkSeq`, ≤ 32 КБ, общий счётчик stdout/stderr), типы и `SshListener` |
| `android/.../secrets/SecretStore.kt` | Пароль, закрытый ключ и его фраза: AES-256-GCM, ключ в Android Keystore (`AndroidKeystoreProvider`), шифротекст в SharedPreferences «cvg-secrets»; `has` → yes / no / unreadable (ключ Keystore потерян) |
| `android/.../secrets/KeyImport.kt` | Проверка ключа при импорте: тип (ed25519, ecdsa, rsa), «нужна парольная фраза», «неверная фраза», «не закрытый ключ» |
| `android/app/src/test/.../ssh/` | JUnit: фикстуры `kh_*` общие с TS; `SshSessionTest` — против sshd на ВМ (тестовый ключ; пароль из `CVG_TEST_SSH_USER`/`CVG_TEST_SSH_PASSWORD`) |
| `assets/logo.png` | Исходник иконки и заставки для `capacitor-assets` |
| `scripts/android-env.sh`, `scripts/check-no-devbridge.mjs` | Окружение сборки (JDK, SDK); проверка, что в бандле APK нет dev-моста |
| `src/core/platform.ts` | `Platform`: `ssh` (`ConnectableTransport`), `prefs`, `secrets` (пароль и ключ — на стороне платформы), `clipboard`, `openExternal` |
| `src/core/api.ts` | `createApi(platform)` — весь контракт `window.api` в одном JS-контексте (события — через `Emitter` по каналам «группа:событие»); тема — `prefers-color-scheme` |
| `src/core/controller.ts` | `AppController`: подключение (шаги tcp → ssh → tmux), все обработчики `window.api`; повторный connect при живом соединении с тем же адресом не переподключается; без сервисов транспорт не закрывается (на Android соединение переживает перезагрузку интерфейса) |
| `src/core/config.ts` | `loadConfig`/`saveConfig` поверх `prefs` и `secrets`: в настройках — только `keyType`; ключ проверяется раньше, чем что-либо пишется; «Импортируйте SSH-ключ или задайте пароль» |
| `src/core/layout-store.ts` | `LayoutStore`: раскладка `{ адрес ВМ: раскладка }` в `prefs` (ключ `layout`), запись с задержкой 300 мс |
| `src/platform/select.ts` | `selectPlatform()`: в сборке `--mode android` — Android, иначе dev-мост (`?bridge=`, `?knobs=`, `?testHooks=1`) |
| `src/platform/dev.ts` | `devPlatform` — мост + localStorage (`cvg:*`) + `navigator.clipboard`; хуки E2E `window.__cvg` (`dropConnection`, `lastLink`) |
| `src/platform/android.ts` | `androidPlatformWith(deps)` — Android-платформа поверх плагина `VmBridge` (контракт `VmBridgePlugin`): события `state`, `lost`, `reconnected`, `hostkey`, `preflight`, `chunks`, `closed`; `connected` — из `status()` при старте и событий `state` |
| `src/platform/android-native.ts` | Сборка платформы из настоящих плагинов Capacitor (Preferences, Clipboard, Browser) — только в `--mode android`; статус-бар следует `html[data-theme]` |
| `src/platform/seq-channel.ts` | `SeqChannel` — канал, собирающий пачки по `seq` (общий для моста и Android); `toB64`/`fromB64` |
| `src/core/emitter.ts` | `Emitter` — замена node:events для кода в WebView (`on` возвращает отписку, `once`, `off`, `emit`) |
| `src/core/transport.ts` | `SshTransport` и `Channel` — SSH-соединение, как его видят сервисы (exec, поток, PTY, запись файла по SFTP, события `state`/`lost`/`reconnected`) |
| `bridge/ssh.ts` | `SshConnection` (ssh2) из 0.2.2 для dev-моста: ключ (файл или импортированный текстом) → ssh-agent → пароль → keyboard-interactive, known_hosts, exec/PTY/SFTP, автопереподключение |
| `bridge/preflight.ts` | `checkTcp`, `runPreflight` — шаги tcp → ssh → tmux (ping убран) |
| `bridge/node-transport.ts` | `NodeTransport` — `SshTransport` поверх `SshConnection`; SFTP-запись с правами 0600 и прогрессом. Для моста и интеграционных тестов |
| `bridge/server.ts` | Dev-мост: WebSocket `127.0.0.1:8790`, одна SSH-сессия на вкладку, секреты в памяти, op `__drop` для E2E |
| `src/platform/bridge-protocol.ts` | Протокол моста: запросы `op`, ответы `{id, ok}`, события `ev`; пачки каналов в base64 с номером `seq` |
| `src/platform/devbridge.ts` | `devBridgeTransport(url)` — `ConnectableTransport` через мост; пачки собираются по `seq`, при закрытии сокета запросы отклоняются `NOT_CONNECTED` |
| `src/core/knobs.ts` | Тестовые настройки вместо переменных окружения: сервер tmux, фейковый claude, каталог Claude Code |
| `src/core/tmux.ts` | `TmuxService`: list/create/kill/startClaude по точному имени (`=имя`), опрос списка |
| `src/core/terminal.ts` | `TerminalService`: `tmux attach` с PTY, send (bracketed paste, Enter — когда поле ввода устоялось, с проверкой, что сообщение ушло — поле опустело или пропало, а не просто изменилось (поздняя отрисовка вставки), — и одним повтором; поле пустое до Enter и после ещё одной паузы — вставка потерялась, ошибка без Enter; поле перестало распознаваться, например bash-режим «!» — Enter вслепую, как раньше), /model, /effort, причина выхода; не пишет в терминал, если открыто меню Claude Code («Esc to cancel») |
| `src/core/hints.ts` | `$HOME/.local/bin` добавляется в PATH для `claude` (часто он есть только в .bashrc).  `HintsService`: команды и модели через `initialize` (кэш), файлы через git ls-files/find, папки по мере ввода |
| `src/core/upload.ts` | `UploadService`: картинки по SFTP в `~/.cache/claude-vm-gui/uploads/`, прогресс, чистка старше 7 дней |
